# ค่ายผู้อพยพ – เซิร์ฟเวอร์ออนไลน์

เพื่อนเปิดลิงก์แล้วเล่นได้เลย ไม่ต้องล็อกอิน (เซฟตัวละครเก็บในเบราว์เซอร์ของแต่ละคน)

## ขึ้นเว็บฟรีด้วย Render (ทำครั้งเดียว)
1. สมัคร github.com (ฟรี) → New repository → ตั้งชื่อ refugee-camp → Create
2. กด "uploading an existing file" แล้วลากไฟล์ในโฟลเดอร์นี้ (server.js, package.json, render.yaml, โฟลเดอร์ public) ขึ้นไป → Commit
3. สมัคร render.com (เข้าด้วย GitHub) → New → Web Service → เลือก repo refugee-camp
4. Runtime = Node, Build Command = echo ok, Start Command = node server.js, Plan = Free → Create
5. รอ 2-3 นาที จะได้ลิงก์ https://ชื่อ.onrender.com ส่งให้เพื่อนได้เลย

## หมายเหตุ
- แผนฟรีของ Render จะหลับเมื่อไม่มีคนเข้านาน เปิดครั้งแรกอาจรอ ~30-60 วินาที
- รันในเครื่องเอง: node server.js แล้วเปิด http://localhost:3000 (Node 18 ขึ้นไป)
- จำกัดผู้เล่น 16 คน ปรับได้ด้วยตัวแปร MAX_PLAYERS

## รองรับผู้เล่นจำนวนมาก (เวอร์ชันเซิร์ฟเวอร์กลาง)
- ตั้งค่าเริ่มต้นรับได้ 120 คนต่อเซิร์ฟเวอร์ (ปรับด้วยตัวแปร MAX_PLAYERS)
- เซิร์ฟเวอร์ส่งเฉพาะผู้เล่นและมอนสเตอร์ที่อยู่ใกล้แต่ละคน เพื่อประหยัดแบนด์วิดท์
- ผู้เล่นที่ได้เป็น "โฮสต์" ของแมพ (เบราว์เซอร์ของเขาคำนวณมอนสเตอร์) ควรใช้เครื่องที่แรงพอ
- ดูสถานะได้ที่ /stats (จำนวนผู้เล่นแต่ละแมพ)
