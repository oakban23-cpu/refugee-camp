# REFUGEE: painted item icons (equipment, sets, materials): 176 icons on 8 sheets

Same game, same grid format as the skill icons and UI icons you already painted (`approved_example/`). **Match that rich hand-painted quality exactly.**

## Style (important)
- **Rich hand-painted fantasy MMORPG item icons**, like premium mobile RPG inventories: real painted materials (leather, wood, cloth, iron, steel, gold, gems, glass), proper lighting and volume, and a soft magical glow on high tiers.
- **Do NOT make flat icons or gold-textured vector shapes.** Each object keeps its own natural colours.
- One object per cell, centred, **large** (about 75–85% of the cell), on a **dark atmospheric background** that fills the cell (dark navy-violet, slightly lighter in the centre). **No frame, border or rounded corners.** The game adds the rarity frame.
- Weapons are shown **diagonally** (handle bottom-left, tip top-right), like classic RPG inventory icons.
- **Readable at 40 px.** Strong silhouette, high contrast.
- **No text, letters or numbers.** No people, faces or heads: armour and helmets are shown on their own.

## Tier looks (very important)
Equipment comes in **5 tier looks**. The same item type must look clearly **richer and more powerful** at each step, with a different shape detail, not just a recolour:
1. **BASIC**: plain worn materials, leather wraps and dull iron, simple and humble.
2. **ELITE**: polished silver steel, cool blue accents, one small blue gem.
3. **MYSTIC**: dark blued steel, glowing violet arcane runes, a violet gem, magical aura.
4. **RELIC**: ornate royal gold, filigree, fiery orange-red gems, regal.
5. **LEGENDARY**: blackened crimson metal with cosmic star-dust glow in pink-violet. The most ornate, with floating star sparks.
The 5 tiers of one item type sit next to each other in reading order, so make the progression obvious.

## Use the reference pictures
`reference_current_icons/current_items_NN.png` shows the current simple icon in **every numbered cell**. **Keep the same type of object** (e.g. if a helmet cell shows a horned helmet, paint a horned helmet; if an accessory cell shows a necklace, paint a necklace), just painted richly.

## Sheet format (same as before)
- **8 sheets**: `items_01.png` … `items_08.png`, each **1536×1024**, in a **6 × 4 grid** of exactly **256×256** cells with no gutters (`templates/`).
- Cells are numbered **1–24**, left to right and top to bottom. **(empty)** cells stay plain black.
