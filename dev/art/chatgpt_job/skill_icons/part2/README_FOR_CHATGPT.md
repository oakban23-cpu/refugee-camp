# REFUGEE: painted icons, part 2 (68 icons on 3 sheets)

This is the follow-up to the skill icons you already painted. They are in the game now and look great: see `approved_example/`. **Paint this batch in exactly the same style, quality and format** so everything matches.

## Same rules as before
- Hand-painted fantasy MMORPG icon: painted light and volume, glow and particles, and one big bold focal shape.
- **Full-bleed square painting** filling its whole 256×256 cell, with its own dark atmospheric background. **No frame, border, rounded corner or bevel.** The game adds those.
- **Readable at 40 px.** Use high contrast, keep the brightest point near the centre, and avoid fine clutter.
- **No text, letters or numbers.** No realistic people or faces. Stylised silhouettes of creatures are fine where needed. Nothing gory.
- Every icon on a sheet must have a **different silhouette**.

## Sheet format (same grid as before)
- **3 sheets**: `skills_04.png`, `skills_05.png`, `skills_06.png`, each **1536×1024**, in a **6 × 4 grid** of exactly **256×256** cells with no gutters (`templates/`).
- Cells are numbered **1–24**: left to right, top to bottom (row 1 = cells 1–6, row 2 = 7–12, row 3 = 13–18, row 4 = 19–24).
- Cells marked **(empty)** must be **plain black**.
- `reference_current_icons/` shows the current simple icon in each numbered cell, so you can see the intended idea.

## Sheet 06: link runes (23 icons)
These are **support runes** that players socket onto any skill to change how it works. They are shared by all classes, so do **not** use the class colours. Paint each one as a **glowing rune gem / carved rune-stone medallion** that sits in the centre of the cell over a dark background. The symbol is carved into or glowing inside the gem. The game shows these inside a **circle**, so keep everything important inside a centred circle about 85% of the cell width. All 23 should look like **one matching set**: the same gem shape language and lighting, but a different colour and symbol for each.
